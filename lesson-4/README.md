# Описание

В проекте через `docker-compose` разворачивается WordPress (в связке Nginx, PHP-FPM, MariaDB), система мониторинга Prometheus с набором экспортеров и графана. Согласно заданию, Были созданы дашборды infra и app, infra - базовое состояние хоста и ресурсов хоста, app - то как отвечает приложение и отвечает ли оно вообще.

# Запуск

```bash
docker-compose up -d
```
